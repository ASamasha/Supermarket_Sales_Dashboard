# 🛒 Supermarket Sales Dashboard (SQL + Power BI)

## 📌 Project Overview
This project analyzes supermarket sales data using SQL and Power BI. It transforms raw transactional data into interactive dashboards for business decision-making.

---

## 🎯 Objectives
- Analyze sales performance
- Identify best-selling products and branches
- Understand customer behavior patterns
- Build an interactive Power BI dashboard

---

## 📊 Dataset
- Source: Supermarket sales dataset (MySQL / XAMPP)
- Records: 1000+ transactions
- Features: Invoice ID, Branch, Product Line, Sales, Quantity, Payment Method, Rating

---

## 🧹 Data Cleaning
- Removed missing values
- Fixed data types
- Standardized categories
- Added:
  - Month column
  - Day Name column

---

## 🧠 SQL Analysis
- Monthly Sales Trends
- Branch Performance Analysis
- Product Line Analysis

---

### 🟦 Supermarket Sales Dashboard

### 🟩 Product Performance
- Sales by Product Line

### 🟨 Customer Insights
- Gender Analysis
- Customer Type

- Ratings

---

## 📌 Key Insights
- Electronic accessories performed strongly
- Branch A had highest revenue
- E-wallet is most used payment method
- Female customers gave higher ratings
- Sales vary by month (seasonal trend)
